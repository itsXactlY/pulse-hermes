Run it yourself

One-line install — registers as MCP server in Hermes, Claude Code, Cursor, Cline, Codex, Goose:

curl -fsSL https://remainder.online/install.sh | bash

Then from any MCP-aware client:

pulse_search(topic="your topic", depth="wurm", worm_rounds=3)

Or via CLI:

pulse "your topic" --depth wurm --worm-rounds 3 --worm-fetches 500
